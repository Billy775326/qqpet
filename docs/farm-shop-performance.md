# 农场商店性能与默认排序

本次优化针对反复打开商店、切换类别和购买后的操作延迟，沿用原有皮肤、商品价格及存档格式。

## 已调整的行为

- 商品卡片及目录在同一个农场窗口内复用，切回已打开的类别不重新读取目录。卡片缩略图停止不必要的时间轴播放，装饰子对象不再参与独立鼠标命中检测。
- 悬停时共用一个提示层，补充农场解锁等级、购买价、成熟时间和作物出售单价；离开商品或关闭商店时移除提示，保留原有商品说明。
- 购买后保留滚动位置，在店内显示结果。鼠标滚轮与原滑块同步，滚动范围限制在列表首尾。
- 商店展开动画由 0.5 秒缩至 0.16 秒，购买窗展开由 1 秒缩至 0.15 秒，关闭由 1 秒缩至 0.12 秒；原有连续点击保护保留。
- 数量限定为 1–99。等级或余额不足时禁用确认，购买时再次校验条件；余额变化后刷新卡片状态，保留商品顺序与滚动位置，已有卡片继续复用。

## 测量结果

2026-11-05 在 Windows、隔离的无头 Chrome、Ruffle 0.6.0、800 × 650 视口及 DPR 1 下测量。基线为 `14dc5fb` 的农场资源，优化后样本为 `70609ae` 的资源；通过同一类测试用 Flash 回调读取界面完成状态和卡片对象身份，不使用真实存档。

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| 连续三次打开商店，累计出现的卡片对象数 | 20、40、60 | 20、20、20 |
| 三次商店展开完成的平均耗时 | 约 561 毫秒 | 约 230 毫秒 |
| 一次购买窗展开完成的耗时 | 约 1,043 毫秒 | 约 200 毫秒 |

这是同一测试环境的一轮观测，包含动画等待和读取完成状态的耗时，不是整机 FPS 或所有机器上的性能承诺。相应回归命令是仓库根目录下的 `node scripts/test-farm-popup.mjs`，环境变量及报告路径见 README。

## 默认商品排序

商店按以下默认顺序排列，商品编号及目录内容不变：

1. 农场等级已解锁的商品优先。
2. 所需农场等级从低到高。
3. 作物出售单价从低到高。
4. 前三项相同，再按种子购买价从低到高；完全相同时保留目录顺序。

余额不足时淡化商品、提示并禁用购买，不参与位置排序，购买前后商品位置保持稳定。

当前一级的白萝卜、苹果、葡萄出售单价均为 18 元宝，种子购买价分别为 80、75、70 元宝，因此显示为葡萄、苹果、白萝卜。成熟时间排序仍属于可选方案讨论，尚未提供切换入口。
