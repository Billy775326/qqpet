# QQPet v0.3.0 升级说明

v0.3.0 基于 v0.2.0，整合物品收藏分类、邮件发放、库存事务、池塘批量投放和托管培养安排，并修复商城页签、高清文字及独立游戏窗口。项目仍处于 0.x 阶段；本次版本保持既有存档格式，新增配置按默认值兼容读取。

## 主要变化

- **物品分类与收藏保护**：普通 243 种、珍藏 219 种、稀有 52 种、历史绝版 395 种，共 909 种。图鉴按四类显示，历史藏品默认折叠，物品详情显示类别。稀有／绝版仅在最后一份或批量用尽时确认，托管使用多余份数并保留一份。
- **全物品领取与邮箱**：工具入口将食物、清洁用品、药品、玩具每种各 1 份发送至邮箱，共 888 种；确认后不自动打开邮箱。取消不发送，同类未收取邮件不会重复堆积。领取附件合并库存、图鉴与邮件状态为一次保存，失败时保留原状态。
- **19 件玩具**：补齐原素材的定义，加入商城和成长奖励；保留原奖励及已领取状态，已领取目标不补发新增玩具。
- **池塘批量投放**：一次选择投放数量，实时检查余额、等级、会员条件和剩余位置，整批扣款与鱼苗一起保存。普通最多 3 个位置、粉钻最多 5 个，原有鱼的成长和收获规则保留。
- **托管培养安排**：专一培养可锁定学习科目／工作岗位，均衡培养按阶段或较低属性推进；沿用每日任务额度和真实耗时，升学考试及小游戏仍手动。农场新增默认关闭的自动浇水、除草、杀虫，不自动购买、播种、施肥或收获。
- **界面与游戏修复**：商城两排页签、子分类文字和高清素材边框对齐；贴心宝贝标识保留原版文字，避免错误高清重绘造成重影。独立小游戏在首次绘制后显示窗口与任务栏入口，“游戏”分类默认音量为 30%，宠物、池塘、农场和密室保留原默认音量。

“历史绝版”表示描述所指的原活动入口在当前版本未提供。按所有者确认，本版保留既有奖池、普通邮件、任务和商城渠道，因此部分历史绝版物品仍能通过通用奖励获得。完整分类理由见[物品分类说明](../item-rarity.zh-CN.md)。

## Windows 便携版升级

1. 正常退出旧程序，备份整个旧版目录。
2. 将新 ZIP 解压到新的可写目录，把旧版整个 `data/` 复制到新目录，再启动 `QQPet.exe`。不要在运行中覆盖程序或存档。
3. 确认宠物、库存和设置后再处理旧目录。需要回退时，恢复备份的旧程序及对应数据，避免旧程序覆盖新存档。

已有宠物、合法库存、图鉴、邮箱、照片邮件、任务进度和领奖状态保留，不回收物品或补造历史操作。新的培养方式默认专一培养，默认科目为语文；没有固定岗位时沿用自动选岗。农场自动照料默认关闭，已有自动购买和每日任务开关不擅自开启。

密钥继续使用系统安全存储，同机同系统用户保留整个 `data/` 可继续恢复；更换电脑或系统用户可能需要重新输入。普通 JSON 导出不包含密钥，也不能代替整个数据目录的备份。本版没有提高最低系统或运行时要求，Android 版本继续从同一份 `package.json` 读取。

## 验证结果

发布候选在 Windows、Node.js 24.16.0 和 Electron 44.10.0 下完成：

- 132 项单元测试、TypeScript 检查及生产构建。
- 全部 19 套隔离界面回归，包括 1,400 组分辨率／缩放／任务栏工作区模拟、商城 24 组普通／高清页签及 54 组子分类布局、真实池塘 SWF 批量投放、邮件事务和收藏保护。
- 实际农场 SWF 商店及购买弹窗回归。
- Windows 实际便携构建的三次启动，验证模拟密钥加密、重启恢复、清空和存档排除；5,154 个源资源与打包资源的 SHA-256 校验。

测试使用隔离数据，不在真实宠物存档执行辅助领取或物品消耗。本轮没有切换真实桌面的任务栏配置；模拟工作区及原生窗口测试不能代替全部混合 DPI 多屏实测。发布工作流使用 Node.js 22，分别执行 Windows、macOS、Linux 的单元测试、构建和资源校验；Windows 另做便携启动检查。跨平台最终结果以本次发布工作流为准。

## 已知限制与依赖审计

- 桌面构建未进行代码签名；Android APK 只有配置发布签名时才提供，以 Release 实际附件为准。
- 池塘和农场继续使用原 Flash 图形指针，受原 24／20 FPS 限制，尚未改成独立高刷新指针。
- Windows 便携模式约束应用自身的数据位置，不保证系统、驱动或安全软件不留下运行记录。
- 2026-11-07 的 `npm audit` 报告 8 条中危构建依赖告警，来自两项根公告，没有高危或严重项。`glob` 的取消后继续遍历问题修复于 14.0.2；`minimatch` 的模式放大拒绝服务问题修复于 11.0.1。受影响节点全部为开发依赖，本次便携包不包含这些 Node 模块；本版保留现有打包依赖范围，未强行覆盖主版本。构建环境应仅使用可信仓库与构建配置。来源：[glob 公告](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4)、[minimatch 公告](https://github.com/advisories/GHSA-g3hv-75wg-m249)。

从同一 Release 下载程序与 `SHA256SUMS.txt`，核对 SHA-256 后使用。哈希用于核对下载内容，不等同于代码签名。
