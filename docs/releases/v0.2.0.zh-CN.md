# QQPet v0.2.0 升级说明

本版本基于 v0.1.4，包含成长任务、托管与商城改进，以及农场购买、透明窗口进度条和托盘交互修复。完整条目见[更新日志](../../CHANGELOG.md)。项目仍处于 0.x 开发阶段，本次按实际变化说明兼容范围。

## 主要变化

- 任务表保持原有布局，增加 68 项永久成长目标，每项搭配实物奖励，元宝作为补充；奖励明细见[成长任务奖励](../task-rewards.zh-CN.md)。
- 托管设置合并为紧凑单页，可分别选择喂食、清洁和玩耍用品及触发比例，共用自动购买开关；可选自动完成可托管的每日任务并领奖，小游戏和升学考试保留手动操作。
- 商城显示粉钻、贴心宝贝剩余天时分秒，悬停图标、名称或倒计时查看原风格到期提示，空白处不触发；支持本地模拟元宝充值，未接入真实付款。
- 农场商店复用目录和商品卡片，支持滚轮，购买后保留滚动位置；修复点击种子出现窄白框、反复打开弹窗缩小的问题。池塘和农场使用各自明确的购买条件与等级、出售单价排序。
- 补充课程“准备考试”提示，改进系统设置、粉钻二级菜单、左右贴边 mini 和任务栏边界处理，修复档案进度条接缝及托盘弹窗优先级问题。

## 升级和数据兼容

1. 正常退出 QQPet，备份整个原便携目录。不要在程序运行时覆盖文件。
2. 将新 Windows ZIP 解压到新目录，再将旧目录的整个 `data/` 复制到新目录。该目录包含存档、浏览器存储、凭据及其他应用数据；首次运行前完成复制。
3. 运行新目录的 `QQPet.exe`。如需回退，使用备份目录及其中原来的数据，避免让旧版本覆盖新存档。

已有存档、配置、任务进度和领奖记录保留。新增配置提供默认值；自动购买及自动完成每日任务默认关闭。没有历史累计记录的操作不推算过去次数。已领取的成长奖励不回收或补发，未领取的采用新方案。

装扮背景的基础有效期由分钟改为天，数值不变；已启用背景保留原剩余时间，重新使用后采用新时长。贴心宝贝充值后剩余时长最多 30 天；已有超出上限的记录保留到期时间，未降至可续范围前不能继续充值。关闭托管不会暂停有效期倒计时。

API Key 仍由系统安全存储保护；同机同系统用户保留 `data/` 可继续使用，换机器或系统用户可能需要重新填写。普通存档导出不包含 API Key，也不能替代整个 `data/` 的备份。

## 已知限制

- 池塘和农场仍使用原 Flash 图形指针，其显示受原始 24／20 FPS 限制；独立高刷新指针尚未实现。
- 界面测试覆盖模拟分辨率、DPI 与任务栏工作区组合，不能保证所有真实显示器、混合 DPI 多屏或平台窗口管理器的表现完全一致。
- 桌面安装包未进行代码签名。Android APK 仅在仓库配置发布签名时提供，实际产物以 Release 附件为准。
- Windows 便携模式约束应用自身数据位置，不保证操作系统、驱动和安全软件不留下运行记录。

## 构建与校验

本地验证命令及隔离测试要求见 [README](../../README.md)。发布工作流在 Windows、macOS、Linux 上执行单元测试和打包，并校验外部资源；Windows 额外执行便携启动测试。

发布前在 Windows 完成 85 项单元测试、类型检查、生产构建、全部 15 组界面回归（含 1,400 组分辨率／缩放／任务栏工作区组合）、实际农场 SWF 购买回归，以及 5,154 个源资源的 SHA-256 核对。本轮未重新切换真实桌面的任务栏设置；模拟工作区验证和窗口逻辑测试不等同于全部真实硬件实测。跨平台产物以本版本发布工作流结果为准。

从同一 Release 下载产物和 `SHA256SUMS.txt`，核对 SHA-256 后使用。哈希校验用于确认下载内容与发布附件一致，不等同于代码签名或安全认证。
