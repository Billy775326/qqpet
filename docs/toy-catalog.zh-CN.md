# 新增玩具定义与获取清单

本次将资源目录中 19 张未注册的玩具图片接入背包、商城和成长任务。保留原图与文件名，使用稳定 ID t0009–t0027，避开旧存档会移除的双下划线 ID。原有 8 件玩具的定义和商城第一页保持不变，新玩具追加在第 2–4 页。

以下名称来自素材文件名；描述、价格、等级和使用收益是本次按现有玩具体系补充的设计，不是恢复得到的原版数值。它们均为玩具，包括糖果、手巾等造型，不作为食物或清洁用品使用，也不操作农场或播放器。

每次玩耍消耗 1 件，增加表中心情（不超过当前上限）及属性；沿用现有通用玩耍动作并计入玩具任务。均无粉钻限制、成长加速或持续效果。购买遵循表中等级、余额及现有粉钻八折；任务奖励放入背包，不自动使用，已拥有的奖励玩具遵循现有库存使用规则。

每种都有“商城重复购买 + 一个成长目标奖励”的正常来源，因此按“整份存档仅一次机会才是稀有、没有途径才是绝版”的定义，均属于可重复获取。不会改动已有随机奖池；已领取目标不补发，未领取目标在原奖励外追加对应玩具 1 件，进度和目标 ID 不变。
