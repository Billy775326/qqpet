# QQPet 使用指南

介绍桌面交互、商城、会员、托管、任务和数据备份。下载安装见 [README](../README.md#下载安装)，版本兼容变化见 [v0.2.0 升级说明](releases/v0.2.0.zh-CN.md)。

## 桌面交互与贴边收起

QQPet 支持左右缘 mini：将宠物拖到屏幕左缘或右缘松手后收起，鼠标移入时探头，点击或拖离边缘后在对应一侧展开；左侧形象镜像显示，重启后保留收起位置。空闲 3 分钟显示小憩效果，养成与任务照常运行。托盘喂养和设置中的召回也会恢复完整宠物。

“活动 → 游戏”入口内所有分类的游戏，打开时播放器音量默认设为 30%，包括“陪我玩”的桌面小游戏和 QQ 飞车等独立窗口游戏。池塘、农场、密室及宠物本身保留原来的默认音量。临时调整可使用 Windows 音量合成器中 QQPet 对应的应用滑条；“免打扰模式”只关闭聊天气泡，不控制游戏音量。

## 商城与装扮

商城“功能 → 玩具”第 2–4 页新增羽毛、铃铛、足球、蓝色 MP3 等 19 件玩具，按标注等级和元宝价格可重复购买，无粉钻限制。19 项成长目标也各追加一件对应玩具，已领取目标不补发。玩耍消耗一件并恢复心情，部分增加少量属性；定义和获取清单见[玩具目录](toy-catalog.zh-CN.md)。

### 本地模拟充值

点击商城底部“元宝”两字可打开充值弹窗：可选 6、30、98、198、328、648 六档，默认按 1:10 增加元宝；同一次充值弹窗内累计点击 648 档位 10 次后，本次弹窗的所有档位改为 1:100，关闭后恢复 1:10 并清零点击计数。选择档位不增加元宝，仍须确认。这是本地模拟充值，不涉及实际扣款；原设置中的作弊页已移除。

### 背景有效期

装扮背景的基础有效期按天计算，例如原 60 分钟现在实际使用 60 天；“无背景”不显示时间。已经启用的背景保留原剩余时间，重新使用后采用新时长。倒计时存档仍以分钟保存，其他限时物品的时长不变。

## 粉钻与贴心宝贝

### 入口与粉钻续费

控制条“粉钻”提供“粉钻”“贴心宝贝”和“商城”三个二级入口，贴心宝贝使用档案中的爱心图标；档案中的粉钻和贴心宝贝图标也可直接操作。粉钻沿用 5 天套餐：符合原有首次优惠条件时 666 元宝，其他开通或续费按当前粉钻等级 × 888 元宝计费；未到期续费从原到期时间追加，取消或余额不足不扣费。

### 剩余时间与到期提示

商城左上宠物预览区底部显示粉钻和贴心宝贝的剩余天、小时、分、秒，每秒刷新；悬停图标、名称或倒计时，可通过商城原有风格的说明框查看准确到期时间，贴心宝贝还会说明托管开关状态，行内空白处不会触发提示。续费即时更新，未开通及已到期分别提示；关闭托管不会停止有效期倒计时，关闭商城后停止界面刷新。会员计费、存档及原有商城布局不变。

### 贴心宝贝续费

贴心宝贝按充值后的实际剩余时长最多 30 天计算，可提前续费：点击状态栏的贴心宝贝图标，查看剩余及本次可充值天数；例如剩余 10 天时最多再充 20 天，费用仍为 300 元宝/天。不满一天的剩余时间按占用一天的额度计算；已有超过 30 天的存档保留原到期时间。开启/关闭按钮仅切换自动照料。

## 托管设置

### 自动照料

点击贴心宝贝说明中“可以送给克鲁尼托管”的“托管”，可打开托管设置。单页展示喂食、清洁、玩耍三行，分别设置饥饿、清洁、心情的触发比例（默认均为 60%）及对应用品。

- 滑条上可用鼠标滚轮或方向键逐 1% 微调，悬停比例可查看当前对应数值。
- 可指定用品或自动选择背包用品。自动购买默认关闭；开启后仅在缺货时按需购买一份，同时适用于三类用品。
- 自动选择模式购买当前类别可买的最低单价用品，遵循等级、粉钻、商城在售及元宝余额限制。
- 详细规则可展开查看，点击“保存设置”后统一生效，取消不保存。

### 自动完成每日任务

托管设置下方可开启“自动完成每日任务并领奖”，默认关闭。范围包括“今日任务、逗逗我、学习打工”以及“旅游任务”中每天重置的目标。

空闲时按正常流程喂食、清洁、玩耍、逗乐、学习、打工和旅游，完成后自动领取各页每日奖励。同一操作会同时推进对应目标，达到当天要求后停止，不重复完成已达标的次数。各页永久目标和地区旅游挑战仍手动领奖，升学考试和小游戏仍需手动操作。

喂养任务遵守各类别的触发比例与用品选择，数值未低于限额时等待自然消耗；缺货补购沿用照料区的自动购买设置。学习、打工和旅游仍需正常耗时。

已有活动或正在操作界面时不启动新任务；正常播放的动画结束后继续，动画切换长时间停绘不会阻塞托管，每轮成长检查最多进行一次操作。关闭开关后不再启动新任务，已开始的活动正常结束。自动照料与活动计时独立于动画回调，关屏时仍按规则执行；宠物生病时暂停自动每日，需要先看病恢复健康。

### 专一培养与均衡培养

“培养方式”决定每日任务中学习和打工的选择。默认“专一培养”，优先语文，岗位默认自动选择；每日目标完成后停止，次日按已保存的进度继续。

- 专一培养：优先科目按小学、中学、大学、研究生推进，等待该科手动考试，通过后继续；研究生毕业后换到下一门未毕业科目。可指定固定岗位，不满足岗位条件时等待并尝试其他每日目标；自动选岗在符合等级、学历和属性条件的岗位中优先时薪。
- 均衡培养：先推进最低学历阶段的科目，已学满等待考试的科目暂时跳过，其他科目晋级前不开始更高阶段的新一轮；打工根据当前智力、魅力、武力的短板选择属性收益较高的可胜任岗位。
- 全科研究生毕业后，仍可用“学无止境”完成每日学习；专一模式继续优先科目，均衡模式优先课次较少的科目。

切换模式不替换已经开始的活动。小游戏与考试保持手动，旅游目的地仍然随机。

### 农场自动照料

“农场自动照料”默认关闭，与自动完成每日任务分别设置，均需贴心宝贝已开启且未到期。保存开启后，农场窗口打开时复用原“一键照料”流程；关闭时照料尚在生长、需要浇水、除草或杀虫的地块，沿用每项照料增加 2 点经验及原等级结算规则。

自动照料不花元宝，不使用肥料，也不购买、播种、收获或铲除。成熟作物继续等待手动收获；关闭农场期间已成熟但尚未结算产量的作物保留原灾害记录。操作宠物或面板时暂缓，宠物暂停成长、死亡或贴心宝贝失效时停止；程序退出后不在后台执行。

## 任务与成长奖励

任务表保留“今日任务、逗逗我、学习打工、旅游任务”四个页签，在同一行提供“成长历程”；列表、奖励图标和领取按钮沿用原有布局。悬停页签可查看规则。

| 目标类型 | 重置规则 |
| --- | --- |
| 每日任务 | 每天 06:00 重置 |
| 地区旅游挑战 | 跨天保留，完成一轮旅行后重置 |
| 永久成长目标 | 跨日、跨轮保留，每项目标奖励领取一次，随存档导入导出 |

永久目标共 68 项，分布如下：

- **逗逗我**：6 项累计逗乐目标，分别为 1／25／100／300／1000／3000 次。
- **学习打工**：12 项课时、打工次数和升学学历目标。
- **成长历程**：50 项照料、等级、累计在线陪伴、学习学历、打工、旅行、图鉴、小游戏及池塘／农场收获目标。

旧存档已有的等级、课时、考试学历、图鉴、可确认的收获和累计逗乐记录会计入。历史喂养、打工等没有总计记录的操作，仅从已有任务计数开始累计，不推算过去次数。

每项目标均提供实际物品，按主题分配食品、清洁用品、玩具和少量背景，元宝作为补充。全部永久目标合计 2300 元宝、54 种物品，具体见[成长任务奖励明细](task-rewards.zh-CN.md)。背景领取后进入背包，不自动替换当前装扮；元宝奖励以可使用的元宝物品放入背包。已领取目标保持原状态，不回收或补发，未领取目标采用新奖励。

课程出现“准备考试”提示后，仍需手动通过升学考试才能获得对应学历。自动托管不会代考。

## 数据备份与 API Key

### Windows 便携数据

Windows ZIP 便携版直接解压运行，应用自身数据存放在 `QQPet.exe` 同目录的 `data/`：存档 `save.json`、浏览器存储与缓存 `browser/`、临时文件 `temp/`、日志 `logs/` 和崩溃目录 `crashes/`。目录不可写时会明确报错，不回退到系统用户目录。移动或备份时请复制整个解压目录；升级时保留 `data/`，不要在运行中覆盖程序。

便携版不设置开机自启，也不自动读取旧安装版的用户目录。旧宠物请在旧版导出后手动导入；导入前会验证存档并备份为 `save.json.bak`。小游戏本地存储与按键设置包含在 `data/browser/` 中，单独导出宠物 JSON 不包含这些浏览器设置。

### API Key 保存方式

桌面版 API Key 单独使用系统安全存储加密，Windows 便携版密文位于 `data/credentials.bin`。同一台电脑、同一系统用户重启无需重新输入；换电脑或系统用户无法解密时会提示重填，不影响宠物存档。

系统安全存储不可用时，密钥仅本次运行有效，不回退到明文。宠物存档、存档备份与 JSON 导出不包含 API Key；复制整个 `data/` 会同时复制加密凭据。清空 API Key 会删除本地密文，更换接口地址会清除密钥以避免误发。Android 暂维持密钥仅本次运行有效。

旧版已存在的外部存档或备份不会被自动删除或清理。便携模式只约束应用自身数据，不保证 Windows、驱动或安全软件不留下系统运行记录。其他平台仍使用其系统应用数据目录。

## Android 使用方式

Android 端以悬浮窗形式显示在桌面和其他应用上方，提供以下适配：

- 首次打开需允许「显示在其他应用的上层」和通知权限；通知栏常驻的通知代替桌面版的托盘图标。
- 宽面板在竖屏手机上自动旋转并铺满屏幕；横竖屏切换后宠物保持在屏幕内。
- 小游戏和密室探险全屏横屏运行，并显示可改键的虚拟手柄。
- 系统不允许后台读取剪贴板：在其他应用里选中文字后，从选择菜单或分享面板选「QQ宠物」，交给宠物点评或翻译。

## 已知限制

- 池塘与农场仍使用原 Flash 图形指针，显示分别受 24 FPS 和 20 FPS 限制，可能有跟手不顺的感觉。
- 分辨率、DPI 与任务栏适配经过模拟组合验证，不能代替所有真实显示器和混合 DPI 多屏实测。
- v0.2.0 未提供 Android APK；Android 工程可按[开发指南](development.zh-CN.md#android-构建与签名)自行构建。
